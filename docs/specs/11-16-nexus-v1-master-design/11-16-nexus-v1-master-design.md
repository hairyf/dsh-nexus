# dsh-nexus 一期总纲

状态：用户已批准（2026-11-16）。日期：2026-11-16。

## 总体目标

将人的管理对象从大量编码会话转为项目、工单目标、待决问题和验收结果，形成 1 个全局入口、N 个项目、N 个实现会话的协作框架。跨项目工作由按需创建的临时协调者承担。实现阶段由 /exec 按子 Spec 执行；本总纲不包含实现任务。

## 范围与非目标

一期覆盖 GitHub 与当前 DSH Web、自动分诊、工单执行、分级提问、交付验收、可中断运行、提醒和恢复，以及现有 Web 面板与侧边对话的复用。

不包含其他协作渠道、项目与仓库多对多、多租户身份体系、另建通用消息总线、侧聊只读权限系统、deep-view 接入或 DSH 升级。deep-view 的后续方向归 Web 子 Spec 记录。

## 依赖与并行组

- 01 先行，统一数据和领域契约，不由下游各改一套状态与权限。
- 02 与 04 依赖 01，可并行。
- 03 依赖 01、02；不以 04 实现完成作为开发前提。
- 05 依赖 01、02、03；与 04 尚未完成的工作可以并行。
- 06 依赖全部子 Spec，负责最后装配和整体核验。
